# Visual source

The user supplied the iPhone, Android and TV boards inline in the design request on November 15, 2026. They were studied before implementation. The original JPEG attachments were not available as local files in this fresh workspace; no substitute reference images are represented as the originals here.

- iPhone board: warm off-white, five-tab navigation, Continue watching, compact guide program sheet, full-width player.
- Android board: dark Material patterns, pill indicator, checked filter chips, artwork-led series detail, outlined playlist fields and M3U / Xtream / File choices.
- TV board: slim icon rail, featured live content, Continue watching, preview-led timeline grid, one remote focus target.

NodeCast branding and actual provider content remain in the application. Reference channels, movie names, logos and sample copy were not imported.

The requested LIVE red (#E5342B) with white text measures 4.32:1. The implementation uses #DD3027 for the requested minimum 4.5:1 text contrast. All other requested base palette values are retained.
