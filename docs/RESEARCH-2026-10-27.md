# Everyday viewing: research and implementation

Research date: October 27, 2026. Selected scope: everyday polish across iPhone, Android mobile and Android TV; local-only storage. This is exploratory desk research, not a representative survey or an independently reproduced competitor bug audit.

## Sources read this round

- [IPTVX App Store reviews](https://apps.apple.com/us/app/iptvx/id1451470024?see-all=reviews): slow playlist entry, cached background refresh requests, restricted listings appearing despite parental controls, guide/library refresh confusion, subtitle defaults, programme search, playback interruptions and intrusive purchase prompts.
- [UHF App Store reviews](https://apps.apple.com/us/app/uhf-love-your-iptv/id6443751726?see-all=reviews): returning to movie navigation, PiP/preview, profile separation, cross-device continuity, next episode/skip intro, playback interruptions, mobile-data download controls and confirmation before deleting downloads.
- [TiviMate Google Play reviews](https://play.google.com/store/apps/details?id=ar.tvplayer.tv&hl=en_US): appreciation for navigation/search/guide, with a request to sync favorites and watchlists between devices (August 2, 2026).
- [Sparkle Google Play reviews](https://play.google.com/store/apps/details?id=se.hedekonsult.sparkle&hl=en_US): mobile seeking/navigation, long-session freezes, unclear timeshift storage setup and recording-duration problems. Developer responses distinguish configuration requirements from failures.
- [Televizo Google Play reviews](https://play.google.com/store/apps/details?id=com.ottplay.ottplay&hl=en_US): Back losing search results (August 15, 2025), selecting channels from future programme results, automatic PiP and casting.
- [TROYPOINT wishlist](https://troypointinsider.com/t/tivimate-feature-wish-list/153806): timeshift, settings sync, scoped search/guide refresh, embedded VLC, stream information, blank playlists and recording reliability. Read the publicly visible first page, not the entire thread.
- [Firecore add-ons discussion](https://community.firecore.com/t/support-for-add-ons/60061): metadata/subtitle/trailer integration requests. Participants disagree about M3U availability; this is not evidence that Infuse supports complete IPTV playlist import.

Apple can repeat review text and developer responses in its page markup; these were not counted as separate observations. Store pages expose selected reviews from mixed dates and versions; no frequency, percentage or ranking is inferred. Direct Reddit requests returned 403, YouTube was unavailable and Facebook did not yield usable discussions. None of their inaccessible posts/comments are claimed as fresh research evidence.

## Chosen implementation

1. Preserve navigation context, explicit search scope and cached browsing. Hide categories by default in general search; Favorites remain available. Separate library and guide refresh/status.
2. Per-channel player/engine/format overrides, inheriting existing defaults; reset removes the override. Only a secondary channel action and player overflow expose the advanced options.
3. Player information uses an allowlist of engine/format/state and numeric counts. A previewable report excludes native error strings, server/stream URLs, credentials, IP and location.
4. Shared season selector, watched marks and Continue series, plus mobile Next episode using the provider's actual ordered queue. Explicit next press, no autoplay, invented episode URLs or intro markers.
5. Embedded VLC saves matching language or reported track-name preferences; native playback reports unmatched audio rather than silently claiming a match.

No new main tab, account/backend, service integration, native dependency or background polling. Version 0.5.0 was subsequently compiled and released for all three editions on October 28; see each edition’s build record for exact binary provenance.

## Storage and compatibility

Old version-2 vaults remain valid. Optional per-channel settings live with the secure profile and are validated. They are isolated by profile/content ID and cleared when provider identity changes. Changes apply next open, without replacing the current playback surface.

Viewing metadata retains ordinary recents (60) plus up to 2,000 older episode states, including manual watched marks; no stream URLs enter the history. Continue watching displays at most twelve cards. Clearing viewing history removes episode progress/marks too. Navigation state and scroll memory are session-local and isolated by profile. No cross-device synchronization is implied.

## Deferred

Full XMLTV programme search; persistent mini-player and capability-tested PiP/casting; consistently gated parental controls; account sync; downloads; DVR/timeshift; multiview; integrated VPN; external metadata and intro markers. These need separate capability, provider, privacy and storage decisions. The IP badge remains an explicit comparison with a saved home IP, not proof of VPN protection.
